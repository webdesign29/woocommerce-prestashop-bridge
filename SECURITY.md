# Sécurité

Ne publiez jamais de secrets, de réglages client ou de données de commande dans les tickets.

Signalez une vulnérabilité via GitHub Private Vulnerability Reporting lorsqu’il est disponible, ou directement à un administrateur de l’organisation Webdesign29.

Les clés d’appairage donnent accès aux fonctions du connecteur. Utilisez une clé propre à la paire de boutiques, HTTPS et des sauvegardes des bases. La version candidate demande une recette avant exploitation.
